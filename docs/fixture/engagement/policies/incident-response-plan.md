# Incident Response Plan

Source: Northstar Managed IT template. Two pages.

## Purpose

Describe how Saguaro Precision Machining responds to a suspected or confirmed security incident.

## Contacts

| Role | Contact |
|---|---|
| MSP account manager | Greg Lindqvist, Northstar Managed IT |
| Owner | Dana Ortiz |
| Office manager / IT liaison | Nadia Haddad |

## Response steps

1. Whoever notices the incident calls Nadia Haddad or Northstar's support line.
2. Northstar investigates and, if needed, isolates the affected device using the RMM.
3. Dana Ortiz decides whether the incident must be reported to DoD within 72 hours, per contract.
4. Northstar documents the incident in a short write-up.

## Reporting

The plan mentions reporting to DoD within 72 hours. It does not mention DIBNET and does not mention the medium assurance certificate required to file a report there.

## Testing

No test record exists. This plan has never been exercised.
