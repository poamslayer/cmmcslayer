# Conditional Access Policy Export

| Field | Value |
|---|---|
| Policy name | Require MFA for all users |
| Users | All users |
| Cloud apps | All cloud apps |
| Grant control | Require multifactor authentication |
| State | On |

This policy covers Microsoft 365 sign-in only. It does not cover sign-in to SAG-NAS (local NAS accounts over SMB), SHOP-PC-01 (local "shop" account), or CMM-PC (local Windows 7 account).
