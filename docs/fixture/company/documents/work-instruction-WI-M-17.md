# WI-M-17: Haas VF-2 Fixture Setup and Tool Change Procedure

Author: Saguaro Precision Machining, Manufacturing Engineering.

This is a company-authored, generic work instruction. It references no customer part number, no customer drawing, and no customer dimension.

## Purpose

Describe the standard fixture setup and tool change sequence for the Haas VF-2 for any job run on that machine.

## Procedure

1. Confirm the traveler for the job in hand and load the program named on it (load program per traveler).
2. Mount the fixture plate and torque the clamp bolts to the value on the fixture's tag.
3. Zero the work offset using the touch probe.
4. Load tools per the tool list on the traveler; verify each tool number against the turret before starting the cycle.
5. Run a single-block first piece before releasing the cycle to full speed.
6. Log the fixture and tool change on the shop floor log sheet.

Because this instruction only ever says "per traveler" and carries no customer geometry or customer identifying information itself, it is not CUI on its own.
