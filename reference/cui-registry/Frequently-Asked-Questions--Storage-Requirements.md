#  ***Storage Requirements***

#### ***What are the storage requirements for CUI?***

  
During working hours:

When not working in an approved classified open storage area, CUI storage options include locked or unlocked containers, desk drawers, or GSA-approved storage cabinets.  
 

After working hours:

An approved classified open storage area.  
  
When building provides continuous monitoring (e.g., 24-hour security guards or intrusion detection system) - unlocked containers, desks, or cabinets.  
  
When building does not provide continuous monitoring - locked desks, file cabinets, bookcases, locked rooms, or similarly secured areas.  
  
In hotel rooms or other temporary lodgings - locked desks, file cabinets, bookcases, or similarly secured areas.

**DO NOT:**  
  
LEAVE CUI IN UNATTENDED AUTOMOBILES.   
  
VIEW CUI WHILE ON PUBLIC TRANSPORTATION.   
  
DISCUSS CUI ON CELL PHONES WHEN IN PUBLIC AREAS.
